# midiprec
midiproc estimates how precise you would have to be to play a MIDI file on a real 128-key piano. It uses the same kind of number that NaNGD use for Geometry Dash levels, raw precision (24h) in σ/s: the timing precision rate a player needs to finish the "level" in an expected 24 hours of attempts. // Claude code, I did this just for fun purposes.
